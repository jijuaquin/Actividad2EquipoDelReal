Bienvenidos al Portafolio del Equipo

Somos un equipo de estudiantes de la carrera de Ing. en Sistemas Computacionales. En este proyecto integramos las tecnologías de HTML5 para la maquetación semántica, CSS3 para la personalización de estilos y el marco de trabajo Bootstrap para lograr un diseño responsivo y moderno.

Tecnologías Utilizadas

Herramientas y lenguajes modernos para un diseño web profesional.

📄

HTML5

El lenguaje estándar de marcado para estructurar y dar contenido significativo a las páginas web de DelReal y Asociados.

🎨

CSS3

Utilizado para dar estilo, colores, tipografías y adaptar el diseño visual de forma atractiva a todos los dispositivos.

🟣

Bootstrap 5

El framework CSS frontend que permite construir componentes responsivos, barras de navegación y sistemas de rejilla rápidamente.
